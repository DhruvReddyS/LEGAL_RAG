# Presentation artifacts

This directory contains the reviewable presentation and diagram artifacts for
the Corpusil system architecture. Tool-specific working directories and
intermediate validation output are intentionally excluded from version
control.

## Files

- `Corpusil_Architecture_Slide.pptx` — latest editable architecture slide.
- `Corpusil_Final_System_Architecture.pptx` — earlier finalized PowerPoint
  architecture export, retained for comparison.
- `corpusil-architecture.html` — standalone interactive architecture diagram.
- `corpusil-architecture.svg` — architecture diagram in vector form.
- `corpusil-clean.svg` — simplified vector version used by the latest slide.
- `slide-preview.svg` — preview of the earlier slide composition.

The written source material and diagram-generation brief live in
`docs/paper/ARCHITECTURE_COMPONENTS.md` and
`docs/paper/LUCIDCHART_ARCHITECTURE_PROMPT.md`.
